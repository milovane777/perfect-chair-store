## 이 자료가 공개 저장소에 있는 이유

담당자가 바로 내려받을 수 있도록 **임시로** 공개했습니다.
앱 소스 저장소(`perfect-chair`)는 비공개 그대로이며, 여기에는 제출용 자료만 있습니다.

**제출이 끝나면 이 저장소는 삭제합니다.**
